## 0.1.9 - 2026-11-12

Atlas 0.1.9


## 0.1.8 - 2026-11-11

When a chart hover card opens below, it now sits under the bar, square or point, so you can still see what you are pointing at.


## 0.1.7 - 2026-11-11

Chart hover cards near the top of a page now open below the point instead of being cut off.
On a Mac, the Keyboard shortcuts sheet no longer runs long key names into the text beside them.


## 0.1.6 - 2026-11-11

A new switch in Settings counts cache reads and writes in your token totals, and hovering any token number shows every kind added up.
The Library explains an empty catalog and adds the official one in a click.
On a Mac, the launch animation now hands straight to the window, and the first launch no longer flashes an error while your chats are read.


## 0.1.5 - 2026-11-11

A calmer, more polished Atlas: a slimmer sidebar, clearer charts and icons, smoother sheets, and sessions grouped by folder.
On a Mac, the top strip holds only the window buttons, and the sidebar buttons sit in one row above Dashboard (a neat square when the sidebar is folded).
On a Mac, Atlas now finds Claude Code installed with Homebrew, npm, Volta or nvm, even when opened from the Dock.


## 0.1.4 - 2026-11-10

A calmer, more polished Atlas: a slimmer sidebar, clearer charts and icons, smoother sheets, and sessions grouped by folder.
On a Mac, Settings and Wrapped now stay inside the folded sidebar.


## 0.1.3 - 2026-11-10

A calmer, more polished Atlas: a slimmer sidebar with its four buttons in one row, clearer charts and icons, and smoother sheets.
Sessions are grouped by folder, long names wrap instead of scrolling sideways, and the editor can fill the window.


## 0.1.2 - 2026-11-10

Updates no longer stop with "Error opening file for writing" while Claude Code is using Atlas.


## 0.1.1 - 2026-11-10

Atlas now shows up when you search for it from the Start menu.
Setup puts Atlas on your desktop too, and Settings can take it off again.
Atlas chat replies are shorter, with a plain estimate line.
Lists and filters no longer hide behind each other in a small window.
